# ToolMK
Tools untuk mempermudah mengerjakan matematika.

## Versi
1.0.0

## Fitur
-Menu utama:
 -Kalkulator:
  -Penjumlahan
  -Pengurangan
  -Perkalian
  -Pembagian

## Bahasa
Python

## Cara menggunakan
1. Install Python
2. Clone repository menggunakan git clone
3. Jalankan script dengan cara python3 ToolMk.py
4. Pilih menu sesuai keinginan
