# 🧮 ToolMK

**ToolMK** adalah program berbasis Python yang membantu mempermudah perhitungan matematika, mulai dari operasi dasar hingga perpangkatan dan akar.

<p align="center">
  <strong>Versi 1.0.8</strong>
</p>

---

## ✨ Fitur

ToolMK menyediakan beberapa fitur perhitungan yang dapat dipilih melalui menu utama.

### ➕ Kalkulator
Melakukan operasi hitung dasar, baik bilangan biasa maupun desimal.

| Operasi | Bilangan biasa | Bilangan desimal |
|---|:---:|:---:|
| Penjumlahan | ✅ | ✅ |
| Pengurangan | ✅ | ✅ |
| Perkalian | ✅ | ✅ |
| Pembagian | ✅ | ✅ |

### 🔢 Pangkat dan Akar

- Pangkat dua (kuadrat)
- Pangkat tiga (kubik)
- Akar pangkat dua (akar kuadrat)
- Akar pangkat tiga (akar kubik)

---

## 🐍 Bahasa Pemrograman

ToolMK dibuat menggunakan **Python**.

---

## 🚀 Cara Menggunakan

### 1. Siapkan Python

Pastikan Python sudah terpasang di perangkat. Periksa instalasi dengan perintah:

```bash
python --version
```

### 2. Clone Repository

Salin repository ToolMK ke perangkat:

```bash
git clone https://github.com/HANZZ-C0D1NG/ToolMK.git
```

Masuk ke folder project:

```bash
cd ToolMK
```

### 3. Jalankan Program

Jalankan file utama dengan perintah:

```bash
python3 ToolMk.py
```

Jika perintah `python3` tidak tersedia, coba:

```bash
python ToolMk.py
```

### 4. Pilih Menu

Ikuti pilihan yang ditampilkan pada program, lalu pilih fitur perhitungan yang ingin digunakan.
